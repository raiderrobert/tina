# Triage an incoming bug report

Tina ships no activities; this one exists so the demo has a skill to put in the
prompt. A real activity is installed into `activities/` with napoln.

1. Reproduce the report against `main`.
2. If it reproduces, fix it and open a pull request with a regression test.
3. If it does not, say so in `details` and report `no_action_needed`.
